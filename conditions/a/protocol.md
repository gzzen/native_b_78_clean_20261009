# A — Capsule-level executable workflow projection

One Mother receives every public question in one capsule and its official data. It performs one coherent scientific analysis, reuses valid capsule-level state across questions, executes substantive analyses, and returns structured results. All task-specific multi-line code is persisted under `analysis/scripts/` before execution and is frozen with provenance.

A has one fresh call per capsule, no retry, no reflection pass, no multihead decomposition, no solver-visible evaluator, and no clean-room re-run. Every resolved result cites its persisted `analysis/scripts/` computation source in `evidence`. Compliance is graded: true isolation/private-access breaches and inline-only substantive computation fail the capsule; reproducibility defects attributable to one question suppress only that question; package probes, simple inspection and deterministic formatting normalizations are soft warnings. `common/` supplies only answer-blind integrity infrastructure; it supplies no scientific workflow, grounding, repair, or aggregation capability.
